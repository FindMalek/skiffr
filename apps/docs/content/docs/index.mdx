skiffr is an open-source Chrome extension that fills job applications from your own profile, and never submits anything for you. A dashboard keeps your profile, answers, a job queue and stats. You host the api and the database yourself, with one command: see [install in 5 minutes](/docs/install). It is in early development and releases come out of `main` automatically. The extension detects forms, asks, fills them and learns from your edits today, with the limits listed in [how skiffr learns](/docs/learning).

The repo is a turborepo with a landing page, a dashboard with login, an api, and the extension, wired to postgres with pgvector, auth and typed rpc. Edit these pages in `apps/docs/content/docs`, they are plain mdx.

## What is in the repo

- `apps/web`: the landing page. It only talks to the api
- `apps/dashboard`: profile, answers, queue, stats, Gmail, sources and tokens. It only talks to the api
- `apps/api`: orpc on bun. The only app that touches the database, auth and providers
- `apps/extension`: the Chrome extension (WXT, React, Manifest V3). It calls the api with a token
- `apps/e2e`: the Playwright suite that drives the built extension
- `apps/docs`: this site
- `packages/*`: shared code, see [structure](/docs/structure)
