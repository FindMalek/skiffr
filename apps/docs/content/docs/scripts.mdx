---
title: Scripts
description: Every command in the root package.json.
---

| Command | What it does |
| --- | --- |
| `pnpm dev` | all apps and the extension dev server |
| `pnpm dev:web` | web and api |
| `pnpm dev:dashboard` | dashboard and api |
| `pnpm build` | build everything with turbo |
| `pnpm check` | biome format and fix |
| `pnpm lint` | biome and oxlint, no fixes |
| `pnpm check-types` | typescript across the repo |
| `pnpm test` | tests in every package |
| `pnpm e2e` | build the extension and run the playwright suite in `apps/e2e` |
| `pnpm snapshot <url>` | turn a public application page into a sanitized fixture, see [form snapshots](/docs/snapshots) |
| `pnpm zip` | zip the extension |
| `pnpm db:up` / `db:down` | local postgres |
| `pnpm db:generate` | write a migration from the schema |
| `pnpm db:migrate` | apply migrations |
| `pnpm db:seed` | seed the demo data |
| `pnpm --filter api seed:preview` | seed the full preview dataset, see [seeding](/docs/seeding) |
| `pnpm db:studio` | browse the database |
| `pnpm ui:add <component>` | add a shadcn component to `packages/ui` |

Run a single app with turbo, for example `pnpm turbo dev -F docs`.
