# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Be respectful, assume good faith, and keep discussion about the work.

There is no conduct email address. To report unacceptable behavior, either send a private message to the maintainer through the [GitHub profile](https://github.com/FindMalek), or file a private vulnerability report on this repository (Security tab, "Report a vulnerability") and say it is a conduct report. The maintainer enforces this code of conduct and handles reports in private.
